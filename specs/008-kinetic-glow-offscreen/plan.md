# Implementation Plan: Kinetic Glow Offscreen Buffer & Bezier Curve Optimization

**Branch**: `008-kinetic-glow-offscreen` | **Date**: 2026-08-05 | **Spec**: [spec.md](./spec.md)

**Input**: Feature specification from `/specs/008-kinetic-glow-offscreen/spec.md`

## Summary

Kế hoạch này thực hiện tối ưu hóa đồ họa 165 FPS cho hệ thống Side Art Kinetic Strings và Visual FX qua 3 cải tiến chính:
1. **Offscreen 0.25x Buffer Canvas Engine**: Tách quầng sáng Glow sang Canvas ẩn trong RAM với độ phân giải downscale $0.25\times$, giảm 93.75% pixel rasterization overhead. Canvas chính vẽ đè nét lõi sắc nét 1px lên trên.
2. **10px Y-Step & Bezier Curve Optimization**: Chuyển bước lặp uốn sóng dọc $Y$-step từ 1px/4px lên $10px$, nối các mốc bằng `quadraticCurveTo` (Midpoint control point), giảm 90% số lượng toán tử vẽ vector.
3. **Lottie Extermination & Hardware-Accelerated CSS Radial Glow**: Loại bỏ hoàn toàn `public/lotie/gradient_glow.json` và Lottie renderer. Thay thế bằng 2 thẻ `<div>` CSS `radial-gradient` tăng tốc bởi GPU compositor (`will-change: transform`).
